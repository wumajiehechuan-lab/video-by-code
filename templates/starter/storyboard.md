# 分镜 Storyboard

每句旁白一行。`句` 列必须是 `幕id 句号`（从 0 数），与 script.json 一一对应（`build_audio.py --check` 会核对）。
- **指**：这句提到的元素如何被点亮（glow / bump），其余元素是否变淡。
- **动**：这句里图上发生的**一个**体现推进的动作（生长 / 描绘 / 滑移 / 计数）。首幕和末幕可写 `—`。
- **留**：动作结束后留在图上的标记。
- **板书**：右侧板子写什么（本篇用 `—` 表示不启用板书）。
